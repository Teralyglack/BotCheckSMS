# Краткие заметки для защиты

## Тема

Разработка Telegram-бота ChatDigest Bot для автоматизированной обработки переписок с использованием Python и российских AI-сервисов.

## Что реализовано

- Telegram-бот на Python.
- Приём до 20 сообщений за один запрос.
- Поддержка текста, голосовых сообщений, видеокружков, аудио, фото и скринов.
- Распознавание речи через Yandex SpeechKit.
- OCR изображений через Yandex Vision OCR.
- Краткое содержание и тезисы через GigaChat.
- История обработанных переписок в SQLite.
- Экспорт результата в DOCX и PDF.
- Админ-панель со статистикой прямо в Telegram через команду `/admin`.
- Улучшенный UX: кнопки, статусы обработки, понятные сообщения и аккуратное оформление результата.

## Где находится админ-панель

Админ-панель реализована внутри Telegram-бота. Администратор пишет команду `/admin`, после чего бот выводит статистику: количество пользователей, количество обработок, ошибки, популярные форматы результата, типы входных данных и последние обработки.

Такой вариант выбран для MVP, потому что не требует отдельного сайта, авторизации и развёртывания web-интерфейса. В дальнейшем её можно вынести в отдельную web-панель на FastAPI + React.

## Пользовательский сценарий

1. Пользователь отправляет или пересылает сообщения в бот.
2. Бот распознаёт содержимое сообщений.
3. Пользователь нажимает «Готово».
4. Бот предлагает выбрать формат результата.
5. Результат сохраняется в историю.
6. Пользователь может скачать результат в DOCX/PDF.

## Архитектура

Telegram Bot API → обработчики сообщений → MediaProcessor → Yandex SpeechKit / Yandex Vision OCR → GigaChat → SQLite → выдача результата пользователю.
